# Architecture

`frontend/` is a Next.js App Router client; `backend/app/` is a FastAPI service with SQLAlchemy. SQLite is the development default and `DATABASE_URL` selects PostgreSQL. Browser requests use the configured API origin; provider secrets stay in the backend environment. The message and URL risk analyzer uses deterministic local patterns. The separate conversational assistant calls the Gemini `generateContent` API when `GEMINI_API_KEY` is configured. It sends the current question and recent conversation context to the provider; the application does not save assistant chat turns in analysis history. The selected model is configurable with `GEMINI_MODEL`.

Uploads are MIME and signature validated, processed in memory, and discarded when processing ends. Text PDFs are extracted with PyMuPDF. Screenshot and scanned-PDF OCR is off by default; set `OCR_PROVIDER=tesseract`, install the Tesseract executable on the backend host, and optionally set `TESSERACT_CMD` to its path to enable it.

Analysis metadata is owner-scoped. Raw analysis text and uploads are not persisted. `ai.py`, `ocr.py`, `integrations.py`, and `url_safety.py` define provider boundaries. URL checks do not resolve or fetch user-supplied URLs. Reputation and domain metadata are unavailable until a legitimate provider is configured. WhatsApp and Telegram screens are educational examples, not live integrations. Any future messaging adapter must use verified official webhooks, process only messages intentionally sent to the configured business account or bot, and reply with educational safety guidance only.
