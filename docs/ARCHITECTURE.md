# Architecture

`frontend/` is a Next.js App Router client; `backend/app/` is FastAPI with SQLAlchemy. SQLite is the development default and `DATABASE_URL` selects PostgreSQL. Browser requests use the configured API origin; provider secrets remain in the backend environment. The built-in analyzer uses deterministic local patterns. Uploads are MIME and signature validated, processed in memory, and discarded when processing ends. Text PDFs are extracted with PyMuPDF. Screenshot and scanned-PDF OCR is off by default; set `OCR_PROVIDER=tesseract`, install the Tesseract executable on the backend host, and optionally set `TESSERACT_CMD` to its path to enable it.

Analysis metadata is owner-scoped. Raw analysis text and uploads are not persisted. `ai.py`, `ocr.py`, `integrations.py`, and `url_safety.py` define provider boundaries. URL checks do not resolve or fetch user supplied URLs. Reputation and domain metadata are unavailable until a legitimate provider is configured. WhatsApp Business and Telegram Bot API adapters have no active credentials or webhook routes in demo mode. Any future adapter must use verified official webhooks, process only messages intentionally sent to the configured business account or bot, and reply with educational safety guidance only.
